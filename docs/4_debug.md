# 输入检查
+ 传给模型的机器人 state ：主要看第一帧 state 是否正常  
  + 之前有遇到过输入的夹爪值不正常导致模型行为异常的情况，对pi0可能只是导致性能不太好或者在原地持续抖动；但是对于ACT可能直接导致第一次运动幅度过大触发保护性停止
+ 图像是否与数据集中一致（之前没有遇到过因为图像格式出问题的情况）
+ Instruction ：多任务混合训练时，若 Instruction 没有改成新场景，可能会出现同时表现出两个动作的情形
+ 其他模态如触觉等：假如将这类模态加入state中，要注意该类模态是否超出了模型max_token的上限，异常截断可能会导致模型效果不佳

# 模型检查
+ loss 是否正常下降并且收敛
  + 之前直接用双臂的数据集训练单臂时，loss一直很大没有下降
+ 使用离线数据集推理测试模型功能，见 [openpi](../tools/openpi_compare/README.md).
