# 任务设置
+ 背景尽量不要太乱，可以使用幕布遮挡固定背景
+ 单次任务划分：单次任务尽量不要太长，复杂长程任务可以分成多个子任务；单次任务的开始和结束状态相近，且是否完成任务视觉变化不明显时，最好把它拆开
+ 每次任务开始时机器人最好位于同一初始位置
+ 要使模型具有一定的泛化性，需要改变任务物体位置。每个任务物体的放置点可以在九宫格上，或者在某一区域内随机采样
+ 单个任务采集50~200条左右够用

# 相机
+ 采集数据前一定要固定好外部相机位置，或者至少外部相机位置是可恢复的（做标记等）。（相机位置移动会直接导致模型效果差、之前录制的数据全部作废等）

# 数据质量控制
+ 数据中存在黑屏、跳帧（混入了明显不属于该数据或者不属于该时间片的一帧或几帧）、卡帧（相机某一段卡住）的情况时，会导致模型效果不佳
